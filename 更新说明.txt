                        远程桌面管理工具 - 更新说明
================================================================================

版本：2.0.20260824
更新日期：2026-08-24

--------------------------------------------------------------------------------
【本次更新内容】
--------------------------------------------------------------------------------

1. 新增设置按钮与配置管理
   - 工具栏远程桌面按钮右侧新增"设置"按钮（齿轮图标 sz.png）
   - 点击打开设置对话框，支持三大类配置：
     * 连接工具路径：SSH 工具（plink）、VNC 工具（vncviewer）路径配置
     * 连接参数：默认用户名、默认密码、默认 SSH/VNC 端口
     * 界面设置：字体、字体大小、背景颜色
   - 所有配置持久化存储到 SQLite settings 表，程序启动时自动加载

2. 新增 SSH 一键连接功能
   - 双击或右键选择"SSH 连接"时，自动调用 plink 工具
   - 自动传入主机地址、端口、用户名、密码，无需手动输入
   - 工具路径和连接参数可从设置对话框配置

3. 新增 VNC 一键连接功能
   - 双击或右键选择"VNC 连接"时，自动调用 vncviewer 工具
   - 自动传入主机地址和端口，无需手动输入
   - 工具路径可从设置对话框配置

4. 新增 settings 数据库表
   - 表结构：key TEXT PRIMARY KEY, value TEXT
   - 预设 9 个默认配置项（ssh_tool_path, vnc_tool_path, default_username 等）

5. 新增 tool.py 方法
   - run_ssh(host, port, username, password)：根据配置的 SSH 工具类型执行连接，支持 XTerminal、PuTTY(plink)、MobaXterm、FinalShell、Xshell
   - run_vnc(host, port)：调用 vncviewer 进行 VNC 连接

6. 设置对话框优化
   - SSH 工具由路径输入改为下拉选择（XTerminal / PuTTY / MobaXterm / FinalShell / Xshell），默认 XTerminal
   - 背景颜色新增"取色"按钮，调用系统颜色选择器
   - 设置窗口居中显示（参考其他弹窗的 top_master 定位方式）
   - 字体、字体大小、背景颜色配置统一应用到分组树和服务器树，全局样式一致
   - 新增"恢复默认设置"按钮，点击后弹出确认提示，将所有配置重置为初始默认值
   - 保存设置后立即动态应用到主窗口，无需重启软件即可生效

7. 树形控件图标优化
   - 服务器树新增图标列，根据连接类型（RDP/SSH/VNC/URL/Radmin）显示对应图标
   - 分组树新增文件夹图标（展开/折叠状态），顶级节点默认展开，子节点默认折叠
   - 分组展开/折叠状态持久化存储到 settings 表，下次启动自动恢复
   - 图标由 PNG 图片替换为 Font Awesome 6.4.0 离线字体图标（PIL 动态渲染），无需外部图片资源
