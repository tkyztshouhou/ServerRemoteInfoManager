★ 3.0.20260827 更新：
  - FAQ 知识库新增/修改条目对话框完善：改用 grid 布局并居中显示，修复因
    pack 的 expand 耗尽空间导致"保存/取消"按钮被压缩为 1px 不可见的问题；
    保存后状态栏反馈、ESC 关闭放弃更改
  - 主窗口"保存设置"按钮美化：绿系悬停/按下渐变 + 磁盘图标 + 四态视觉反馈
    （默认/悬停/点击/禁用），新增禁用切换方法

1. RDP 连接重构 —— 临时 .rdp 配置文件 + Windows 凭据管理器
   - 连接前先清理凭据管理器中与本次主机相关的旧凭据（TERMSRV/ip），
     避免残留凭据造成密码冲突
   - 将用户名、密码写入 Windows 凭据管理器（cmdkey，列表形式传参，
     密码含 &、|、<、> 等特殊字符时安全）
   - 根据远程桌面高级选项生成临时 .rdp 配置文件：tempfile.mkstemp
     生成唯一文件名，多实例并发连接互不干扰；文件中不含密码，仅含
     连接地址（full address）、用户名与高级选项配置
   - 执行 mstsc 打开该 .rdp 启动连接，高级选项随连接自动生效
   - 远程桌面会话关闭后自动清理：删除凭据 + 删除临时 .rdp 文件

2. 远程桌面高级选项（新增，持久化存储）
   - 支持远程音频位置（本地/远程）、启用剪贴板、映射本地驱动器、
     全屏模式、远程桌面分辨率（多档预设 + 自定义宽x高）
   - 选项修改即时保存到 SQLite（settings 表），程序重启后自动恢复
   - RDP 连接时自动读取并应用这些选项（写入临时 .rdp 文件）

3. Ping 批量检测（新增）
   - 一键遍历服务器树中全部主机，逐台执行 ping 检测
   - 检测期间弹出进度窗口，实时显示"当前/总数"与正在检测的主机
   - 检测完成后在服务器树"状态"列更新图标：网络正常显示绿色 ✓，
     异常显示红色 ✗
   - 后台线程 + 队列轮询刷新界面，检测期间界面不卡死；按钮防重复
     点击（检测中置灰）

4. 主界面新增下方功能区（左右布局）
   - 服务器树下方新增左右布局容器：左侧为服务器说明（沿用既有
     组件），右侧为功能区
   - 右侧功能区为上下结构：上方为 Ping 检测按钮与 FAQ 知识库按钮
     （左右排列、两侧与中间边距均衡），下方为远程桌面高级选项
     配置区
   - 远程桌面高级选项区域占满剩余高度，内容一屏展示、无需滚动

5. 服务器树密码列脱敏

   - 选中行后右键菜单点击"显示密码"，即可在当前行查看明文密码

6. 服务器树列宽优化

7. FAQ 知识库（已实现，3.0 完善）

【不兼容改动】
--------------------------------------------------------------------------------
1. RDP 连接流程调整为：清理旧凭据 → 写入凭据 → 生成临时 .rdp（仅含
   高级选项配置与连接地址，不含密码）→ mstsc 执行 → 会话关闭后自动
   清理凭据与临时文件。连接体验不变，远程桌面高级选项随连接自动生效。
2. 服务器树密码列默认脱敏显示（*********），查看明文需选中行后右键
   "显示密码"。
3. 数据目录变更：数据库 data.db 与日志 logs/ 由"程序所在目录"改为
   用户目录 %LOCALAPPDATA%/ServerRemoteInfoManager/（Program Files
   只读，旧版在该目录写数据会失败）。已发布的 exe 版本数据自动存放于此；
   源码运行时仍沿用项目根目录。
4. 密码存储改为加密：主机密码与「运维智脑」模型密钥不再以明文存入数据库，
   由 tools/secret.py 统一加密（DPAPI 优先、Fernet 回退）。旧版明文数据在
   首次启动时被自动迁移加密，无需手动处理；升级后数据文件须保持一致，
   跨机器/跨用户直接拷贝数据库可能导致已加密内容无法解密。
