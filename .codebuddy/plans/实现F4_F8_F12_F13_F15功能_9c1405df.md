## 需求概要

实现 ISSUES.md 中记录的五个未实现功能：F4（重命名分组）、F8（编辑主机类型）、F12（窗口位置记忆）、F13（ESC关闭弹窗）、F15（RDP凭据残留清理）

## 核心功能

### F4: 重命名分组

- 用户右键菜单选择"重命名分组"后，弹出输入框让用户输入新名称
- 校验新名称不能为空、不能与现有分组重复
- 更新数据库中的分组名称，刷新分组树显示
- 同步更新 item_map 映射关系

### F8: 编辑主机类型（conn_type）

- 在"编辑主机"下拉框中添加"主机类型"选项
- 用户可选择 SSH、RDP、VNC、Radmin、URL 五种连接类型
- 修改后更新数据库并刷新服务器树图标显示

### F12: 窗口位置与大小记忆

- 程序启动时从 settings 表读取 last_window_x, last_window_y, last_window_width, last_window_height
- 若无记录则使用默认值 1366x768+50+0
- 程序关闭前（Destroy 事件）保存当前窗口位置和大小

### F13: ESC 关闭弹窗

- 取消 infoServer.py 第50-51行的 ESC 绑定注释
- 按 ESC 键可关闭当前打开的弹窗（添加/编辑主机、添加/重命名分组、系统设置等）

### F15: RDP凭据残留清理

- 程序启动时扫描 Windows 凭据管理器中所有 TERMSRV/ 开头的凭据
- 检查对应服务器是否仍然存在，若已删除则自动清除残留凭据
- 使用 cmdkey /list 获取凭据列表，cmdkey /delete 清除无效凭据

## 技术栈

- Python 3.x
- tkinter GUI 框架
- SQLite 数据库
- Windows cmdkey 命令行工具（用于凭据管理）

## 实现方案

### F4 - 重命名分组

**位置**: `Object/infoServer.py` 的 `rename_group` 方法（约1298-1306行）

**实现逻辑**:

1. 检查是否选中分组，未选中则提示错误
2. 创建新弹窗 `tk.Toplevel`，包含 Label 和 Entry 输入框
3. 调用 `self.db.exists(new_name, "groups")` 查重
4. 调用 `self.db.update_group(group_id, new_name)` 更新数据库
5. 刷新分组树 `init_groups_data()`
6. 关闭弹窗

**参考现有模式**: 参照 `add_folder_window` 和 `delete_group` 的弹窗结构和交互流程

### F8 - 编辑主机类型

**位置**: `Object/infoServer.py` 的 `edit_server` 方法（约1091行）

**实现逻辑**:

1. 在组合框 values 中添加 `'主机类型'` 选项
2. 在 `edit_da` 函数的 field_map 中添加映射：`'主机类型': 'conn_type'`
3. conn_type 无特殊校验，直接更新即可

### F12 - 窗口位置记忆

**位置**: `Object/infoServer.py` 的 `__init__` 方法（约20-67行）和 destroy 事件

**实现逻辑**:

1. 在 `__init__` 末尾读取设置：

```python
last_x = self.db.get_setting('last_window_x', '50')
last_y = self.db.get_setting('last_window_y', '0')
last_w = self.db.get_setting('last_window_width', '1366')
last_h = self.db.get_setting('last_window_height', '768')
self.master.geometry(f'{last_w}x{last_h}+{last_x}+{last_y}')
```

2. 绑定 Destroy 事件保存位置：

```python
self.master.bind('<Unmap>', self._save_window_state)
# 或在 root 的 protocol 中处理 WM_DELETE_WINDOW
```

3. 实现 `_save_window_state` 方法保存到 settings 表

### F13 - ESC 关闭弹窗

**位置**: `Object/infoServer.py` 第50-51行

**实现逻辑**:
取消注释并修改为正确的 ESC 处理：

```python
self.master.bind('<Escape>', lambda event: self._close_top_window())
```

新增 `_close_top_window` 方法遍历所有 Toplevel 窗口并关闭：

```python
def _close_top_window(self):
    for win in self.master.winfo_children():
        if isinstance(win, tk.Toplevel):
            win.destroy()
```

### F15 - RDP凭据残留清理

**位置**: `tools/tool.py` 的 `too` 类

**实现逻辑**:

1. 新增 `cleanup_rdp_credentials` 方法：

- 执行 `cmdkey /list` 获取所有凭据
- 筛选出 TERMSRV/ 开头的凭据
- 对每个残留凭据，查询数据库确认对应服务器是否存在
- 若服务器不存在，执行 `cmdkey /delete:TERMSRV/ip` 清除凭据

2. 在 `infoServer.__init__` 末尾调用此方法

**安全考虑**: 凭据清理仅在程序启动时执行一次，不影响运行时性能
