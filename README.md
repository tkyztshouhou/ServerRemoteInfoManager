# 远程桌面管理工具

一款基于 Python tkinter 的本地远程桌面管理客户端，支持 RDP、SSH、VNC 等多种连接方式，帮助 IT 运维人员高效管理多台服务器。

## 功能列表

### 主机管理
- 添加、编辑、删除主机记录
- 主机信息包括：主机类型、主机名、IP/域名、端口、用户名、密码、分组、说明
- 编辑主机支持输入校验（主机名/地址查重、端口号数字校验）
- 按分组筛选主机（空分组正确显示空列表）
- 按关键字搜索主机（支持模糊匹配）
- 密码列默认脱敏显示（`*********`），选中行右键"显示密码"可查看明文

### Ping 批量检测
- 一键遍历服务器树全部主机逐台 ping 检测，进度窗口实时显示
- 检测结果写入服务器树"状态"列：正常显示绿色 ✓，异常显示红色 ✗
- 后台线程执行，检测期间界面不卡死

### 连接方式
| 类型 | 说明 | 状态 |
|------|------|------|
| RDP | Windows 远程桌面，经凭据管理器+临时 .rdp 高级选项一键登录（mstsc） | ✅ 已实现 |
| SSH | 支持 XTerminal、PuTTY、MobaXterm、FinalShell、Xshell | ✅ 已实现 |
| VNC | 通过 vncviewer 图形连接 | ✅ 已实现 |
| URL | 浏览器打开链接 | ✅ 已实现 |
| Radmin | Radmin 远程工具（run_radmin） | ✅ 已实现 |

> 所有连接类型在连接前均有二次确认弹框，防止误操作连上生产主机。

### 分组管理
- 创建、删除分组，支持多级分组
- 右键分组可"重命名分组"，重命名后即时持久化
- 分组树图标区分展开（folder.png）/折叠（folder_badge_plus.png）状态
- 单击分组筛选对应主机
- 分组展开/折叠状态持久化，重启后按层级完整恢复（支持任意层级）

### 界面交互
- 鼠标中键点击分组树/服务器树任意位置，释放当前选中焦点
- 界面设置（字体、颜色）保存后立即生效，无需重启
- 服务器说明区、搜索框背景色独立可配，与主界面背景区分
- 顶部按钮区与"主机名或域名搜索"、"服务器说明"标签保持固定背景色，不随界面背景设置变化
- 窗口位置与大小记忆：关闭前自动保存，下次启动自动恢复上次布局
- 服务器树下方左右布局：左侧服务器说明，右侧功能区（Ping 检测 / 远程桌面高级选项 / FAQ）

### 远程桌面高级选项
- 远程音频位置（本地 / 远程）
- 启用剪贴板、映射本地驱动器、全屏模式
- 远程桌面分辨率：多档预设 + 自定义宽x高
- 所有选项即时保存到 SQLite，重启自动恢复；RDP 连接时自动应用
- FAQ 知识库按钮（img/btn-faqzsk.png，191x45）已放置，功能开发中

### 设置
- 工具路径配置（SSH/VNC 工具可执行文件路径）
- 默认连接参数（用户名、密码、端口）
- 界面样式（字体、大小、背景颜色、说明区/搜索框颜色）
- 所有配置持久化到 SQLite 数据库

### 日志
- 操作日志自动记录到 `logs/` 目录
- 按日期分文件存储
- 敏感信息（密码）日志脱敏处理

## 使用说明

### 添加主机
1. 在左侧分组树中双击目标分组（或右键 → 添加主机）
2. 填写主机信息表单
3. 点击"添加"保存

### 连接主机
- **双击主机行**：按该主机的连接类型自动连接
- **右键主机行**：弹出连接菜单，可选择 RDP / SSH / VNC / URL 连接
- **连接确认**：所有类型连接前会弹出确认框，确认后才执行连接

### RDP 连接原理（2.2 版起）
1. 连接前先清理凭据管理器中该主机的旧凭据（TERMSRV/ip），避免密码冲突
2. 将主机 IP、用户名、密码写入 Windows 凭据管理器（cmdkey）
3. 根据"远程桌面高级选项"生成临时 .rdp 配置文件（唯一文件名，不含密码，仅含连接地址与高级选项）
4. 自动执行 `mstsc <临时.rdp>` 启动连接，无需手动输入凭据，高级选项随连接生效
5. 远程桌面窗口关闭后，程序自动删除凭据与临时 .rdp 文件
6. 临时文件名每次唯一，多实例并发连接互不干扰；密码含特殊字符亦可正常连接

### 取消选中主机/分组
- 在分组树或服务器树范围内**点击鼠标中键**，即可取消当前选中并释放焦点

### SSH 连接配置
1. 点击工具栏最右侧的**设置按钮**（齿轮图标）
2. 在"连接工具"Tab 中选择 SSH 工具类型（XTerminal / PuTTY / MobaXterm / FinalShell / Xshell）
3. 在"连接参数"Tab 中填写默认用户名和密码
4. 点击"保存"

> 注：若主机记录中已填写用户名和密码，将优先使用主机记录中的值。

### VNC 连接配置
1. 在设置对话框的"连接工具"Tab 中填写 vncviewer 的完整路径
2. 在"连接参数"Tab 中填写默认 VNC 端口（默认 5900）
3. 点击"保存"

### 编辑主机
1. 右键主机行 → 编辑主机（需先选中主机，否则弹框提示）
2. 在下拉框中选择要修改的字段（主机名/主机地址/端口号/用户名/密码/主机类型/分组/服务器说明）
3. 输入新值后点击"确定"，程序自动校验并立即刷新列表
   - 主机名、主机地址会与其它主机查重
   - 端口号必须为数字
   - 选择"主机类型"会弹出类型选择对话框，可切换 SSH/RDP/VNC/Radmin/URL
   - 修改分组需先在左侧分组树选中目标分组

### 界面样式设置
1. 在设置对话框的"界面设置"Tab 中选择字体、字体大小和背景颜色
2. 点击"保存"后立即生效（无需重启程序）
3. 服务器说明区背景色、搜索框背景色可独立设置，默认白色

### 删除主机
1. 右键主机行 → 删除
2. 或选中主机后点击工具栏"删除"按钮

### 删除分组
1. 右键分组 → 删除分组
2. 注意：删除分组会同时删除该分组下的所有主机

## 常见问题

**Q：SSH/VNC 连接无反应？**
A：请检查设置对话框中工具路径是否正确，确保 plink/vncviewer 可在系统中执行。

**Q：RDP 连接时凭据管理器有什么变化？**
A：连接期间程序会临时写入一条 `TERMSRV/主机IP` 凭据，远程桌面关闭后自动删除；每次连接前还会先清理该主机的旧凭据，避免残留冲突。若程序异常退出导致凭据残留，可手动执行 `cmdkey /delete:TERMSRV/主机IP` 清除。

**Q：RDP 连接会生成临时文件吗？**
A：会生成一个临时 `.rdp` 配置文件，其中**不含密码**（密码经凭据管理器传递），仅含连接地址与高级选项配置；远程桌面关闭后自动删除，文件名每次唯一，多实例并发互不干扰。

**Q：如何查看主机明文密码？**
A：服务器树密码列默认显示 `*********`。选中该行后右键菜单点击"显示密码"即可在当前行查看明文。

**Q：连接时提示"不支持的连接类型"？**
A：该主机连接类型未实现（如 Radmin）。请在添加/编辑主机时选择已支持的类型。

**Q：编辑主机时提示"请先选中要修改的主机"？**
A：编辑前需先在服务器树中点击选中目标主机行。如需取消选中，点击鼠标中键即可。

**Q：密码以明文存储，是否安全？**
A：当前版本密码确实以明文存储在 SQLite 中（日志已脱敏）。RDP 连接不再产生含密码的临时文件。如需更高安全性，建议自行加密后再录入，或联系管理员规划加密存储方案。

**Q：如何备份数据？**
A：已发布版本备份 `%LOCALAPPDATA%/ServerRemoteInfoManager/data.db` 即可；源码运行则备份项目根目录的 `data.db`。也可通过右键菜单的导入/导出功能导出为 JSON。

**Q：安装版保存设置时报 "unable to open database file"？**
A：通常是旧版本把数据写在 Program Files 只读目录导致。当前版本数据已自动存放于 `%LOCALAPPDATA%/ServerRemoteInfoManager/`，重装新版即可解决；若仍有问题，请以普通用户（非管理员）运行，或检查该目录是否有写权限。

**Q：Ping 检测会弹出黑色命令行窗口吗？**
A：不会。Windows 下 ping 子进程已通过 `CREATE_NO_WINDOW` 隐藏，检测期间仅显示进度窗口。

## 打包发布

项目提供一键打包脚本，生成安装版（Inno Setup）与绿色版（RAR）两种发行包。

### 前置依赖
- Python 3.10.11 + `pip install -r requirements.txt`（含 PyInstaller 6.3.0、Pillow）
- Inno Setup 6（生成安装包，默认路径 `C:\Program Files (x86)\Inno Setup 6\ISCC.exe`）
- WinRAR（生成绿色版，默认路径 `C:\Program Files (x86)\WinRAR\WinRAR.exe`）
- `img/app.ico`：程序图标（多尺寸 ICO）

### 打包命令
```powershell
# 在项目根目录执行（需 Bypass 执行策略）
powershell -ExecutionPolicy Bypass -File .\build_release.ps1
```
脚本依次执行：
1. `pyinstaller build.spec --noconfirm --clean` → 文件夹版（供安装包）
2. 设置 `PYI_ONEFILE=1` 后 `pyinstaller build.spec` → 单文件 exe（供绿色版）
3. `ISCC installer.iss` → 编译安装包 `dist/...-Setup.exe`
4. WinRAR 压缩文件夹版 → `dist/...-Portable.rar`
