# 远程桌面管理工具

一款基于 Python tkinter 的本地远程桌面管理客户端，支持 RDP、SSH、VNC 等多种连接方式，帮助 IT 运维人员高效管理多台服务器。

## 功能列表

### 主机管理
- 添加、编辑、删除主机记录
- 主机信息包括：主机类型、主机名、IP/域名、端口、用户名、密码、分组、说明
- 按分组筛选主机
- 按关键字搜索主机（支持模糊匹配）

### 连接方式
| 类型 | 说明 | 状态 |
|------|------|------|
| RDP | Windows 远程桌面（mstsc） | ✅ 已实现 |
| SSH | 支持 XTerminal、PuTTY、MobaXterm、FinalShell、Xshell | ✅ 已实现 |
| VNC | 通过 vncviewer 图形连接 | ✅ 已实现 |
| URL | 浏览器打开链接 | ✅ 已实现 |
| Radmin | Radmin 远程工具 | ❌ 未实现 |

### 分组管理
- 创建、删除分组
- 双击分组展开/折叠子分组
- 单击分组筛选对应主机

### 设置
- 工具路径配置（SSH/VNC 工具可执行文件路径）
- 默认连接参数（用户名、密码、端口）
- 界面样式（字体、大小、背景颜色）
- 所有配置持久化到 SQLite 数据库

### 日志
- 操作日志自动记录到 `logs/` 目录
- 按日期分文件存储

## 环境要求

- Python 3.10.11
- Windows 操作系统
- 依赖库：`tkinter`（Python 标准库，无需额外安装）

## 安装步骤

1. 确保已安装 Python 3.10.11 或更高版本
2. 克隆或下载本项目到本地
3. 首次运行时程序会自动创建 `data.db` 数据库和 `logs/` 目录
4. 运行入口程序：

```bash
python app.py
```

## 使用说明

### 添加主机
1. 在左侧分组树中双击目标分组（或右键 → 添加主机）
2. 填写主机信息表单
3. 点击"添加"保存

### 连接主机
- **双击主机行**：按该主机的连接类型自动连接
- **右键主机行**：弹出连接菜单，可选择 RDP / SSH / VNC / URL 连接

### SSH 连接配置
1. 点击工具栏最右侧的**设置按钮**（齿轮图标）
2. 在"连接工具"Tab 中选择 SSH 工具类型（XTerminal / PuTTY / MobaXterm / FinalShell / Xshell）
3. 在"连接参数"Tab 中填写默认用户名和密码
4. 点击"保存"

> 注：若主机记录中已填写用户名和密码，将优先使用主机记录中的值。

### VNC 连接配置
1. 在设置对话框的"连接工具"Tab 中填写 vncviewer 的完整路径
2. 在"连接参数"Tab 中填写默认 VNC 端口（默认 5900）
3. 点击"保存"

### 界面样式设置
1. 在设置对话框的"界面设置"Tab 中选择字体、字体大小和背景颜色
2. 点击"保存"后重启程序生效

### 删除主机
1. 右键主机行 → 删除
2. 或选中主机后点击工具栏"删除"按钮

### 删除分组
1. 右键分组 → 删除分组
2. 注意：删除分组会同时删除该分组下的所有主机

## 配置项

所有配置存储在 `data.db` 的 `settings` 表中，常见配置项如下：

| key | 说明 | 默认值 |
|-----|------|--------|
| `ssh_tool_type` | SSH 工具类型 | `xterm` |
| `vnc_tool_path` | VNC 工具路径 | `vncviewer` |
| `default_username` | 默认用户名 | （空） |
| `default_password` | 默认密码 | （空） |
| `default_ssh_port` | 默认 SSH 端口 | `22` |
| `default_vnc_port` | 默认 VNC 端口 | `5900` |
| `ui_font` | 界面字体 | `Microsoft YaHei` |
| `ui_font_size` | 界面字体大小 | `10` |
| `ui_bg_color` | 界面背景颜色 | `#F0F0F0` |

## 常见问题

**Q：SSH/VNC 连接无反应？**
A：请检查设置对话框中工具路径是否正确，确保 plink/vncviewer 可在系统中执行。

**Q：连接时提示"不支持的连接类型"？**
A：该主机连接类型未实现（如 Radmin）。请在添加/编辑主机时选择已支持的类型。

**Q：密码以明文存储，是否安全？**
A：当前版本密码确实以明文存储在 SQLite 中。如需更高安全性，建议自行加密后再录入，或联系管理员规划加密存储方案。

**Q：如何备份数据？**
A：备份 `data.db` 文件即可。也可通过导出功能（如有）导出为 CSV/JSON。
